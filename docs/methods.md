## 5. 数据分析 · Data Analysis

### 5.1 主题分析（Thematic Analysis, Braun & Clarke）

采用六阶段框架：

1. 熟悉数据（转录通读）
2. 生成初始编码（initial codes）
3. 寻找主题（themes）
4. 复核主题
5. 定义与命名主题
6. 撰写报告

### 5.2 编码策略（Saldana）

- 参考 Saldaña《质性研究编码手册》选择首轮 / 二轮编码策略（如描述性编码 → 主题编码 / 轴心编码）。
- 本仓库 `analysis/` 保留编码练习与（脱敏）示例。
